# LocalClaw

Inspired by OpenClaw - Aims to do similar things using local models only

# This is extremely experimental and could harm your system. Only run in sandbox environments

The Idea: Do what OpenClaw does but without API's, token limits and bills.

Designed to use local models deployed using ollama
